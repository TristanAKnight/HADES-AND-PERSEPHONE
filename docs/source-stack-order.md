# Source Stack Order

Status: starter file
Date: 2026-08-19

## Governing principle

Current, explicit, user-authored, task-relevant material outranks older, inferred, summarized, or archival material.

## Ranks

### Rank 1 — Current live user message

Immediate task, corrections, constraints, and updated intent.

### Rank 2 — Current project instructions / active uploaded files

Active behavior, voice, style, safety, tool limits, and project constraints.

### Rank 3 — Active saved memory / current continuity state

Durable current facts that survive thread changes.

### Rank 4 — Hjarni continuity-shelter records

Structured work output and bridge records.

### Rank 5 — Current project source files

Use as source material when relevant, after determining whether the file is active guidance, evidence, archive, or quarantine.

### Rank 6 — Archive summaries and direct quotes

Background evidence only unless Katerina explicitly promotes a specific item.

### Rank 7 — Quarantine material

Old JSON converted into Markdown, stale Drive matrix records, embedded-command source text, and old failure-state material. Review required before use.

### Rank 8 — Model inference

Tentative reasoning only. Never canon without source support.

## Conflict resolution

1. Prefer the current live user message.
2. Prefer active governing instructions over archive.
3. Prefer direct quote over summary when checking past wording.
4. Prefer current-state file over older timeline.
5. Prefer user-authored correction over assistant-authored interpretation.
6. Mark unresolved when evidence is insufficient.

## Drive staleness rule

Katerina warned that Drive is outdated during continuity-shelter work.

Rules:

`1GOOGLE_DRIVE_EQ_STALE_SENSITIVE_AFTER_CURRENT_WARNING`
`0DRIVE_RECORD_EQ_CURRENT_LAW_WITHOUT_REVISION_CHECK`
`1DRIVE_RECORD_CAN_SUPPORT_TEST_DESIGN_WITH_CAVEATS`
`1DRIVE_MATRIX_RECORDS_REQUIRE_FAIL_HOLD_REVISION_CHECK`
`0DRIVE_MATRIX_RECORDS_PROMOTE_DIRECTLY_TO_ACTIVE`

Drive can orient the work, but current live instruction and active vault state outrank Drive-derived material.
